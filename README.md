# mend

One command-line tool that applies AI-written edits in four formats (unified diffs, SEARCH/REPLACE blocks, V4A patches and JSON tool calls) to a tree of files, to the specification in the make.fun kit. Node 22, standard library only.

Run: `node main.ts [--format=NAME] [--check] [--strict] [PATCH]`
